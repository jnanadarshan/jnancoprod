    help Help — ESPHome Display Designer

    New: samples, pages, display types, live data

    • Samples (top bar) opens finished designs: OLED, grayscale, TFT, round, e-paper and multi-page. Open one and change anything.
    • Display type (Settings) makes the preview behave like the panel: 1-bit OLEDs light any non-black pixel, grayscale uses one channel, e-paper picks the nearest ink. The generated colours match (Color::WHITE, Color(0, 0, 0, W)).
    • Pages: the tabs above the preview create display: pages:; Deploy adds an example that switches them.
    • More (Elements) adds lines, triangles, polygons, rings, gauges, images, graphs, QR codes, clocks and clip regions.
    • Live data (under the preview) sets fake sensor values and the clock so text, gauges and graphs look real. Nothing from it is exported.
    • File (top bar) groups imports, exports and Save project (everything, including images, as one .json).
    • Exact text: fonts with a TTF (Roboto is bundled) are rasterised like ESPHome does, at the font’s bits per pixel. Turn on “Smooth text preview” for browser text.
    • Install the page as an app (address-bar icon, or the install button) to use it offline.

    Design a screen visually, then copy the generated ESPHome code. No hardware needed to try it.

    Quick start

    1. Set up the screen. Open settingsSettings (bottom-left). Pick your resolution (or add a custom one), switch on E-Ink if you have a paper display, add your fonts in the visual Font manager (or switch it to Code), and list the color IDs you plan to use.
    2. Add elements. Use the widgetsElements button to add Text, Icon, Bar, Rectangle or Circle. Click one in the list to edit its position, color and font, or drag it directly on the preview.
    3. Check the preview. Use HD for a smooth view and zoom_out_map to scale large screens to fit.
    4. Generate code. Bottom-right, press Color Code, Font Code and Generate Lambda, then copy each result.
    5. Put it on a device. Press rocket_launchDeploy in the top bar for a step-by-step ESPHome guide with your own code filled in.

    The three code buttons

    paletteColor Code

    A color: block defining your custom Color IDs. Goes at the top level of your YAML.

    font_downloadFont Code

    A font: block, one entry per font ID. Needs the matching .ttf files next to your YAML.

    codeGenerate Lambda

    The drawing instructions. Goes under display: → lambda:.

    Writing good text elements

    • Font IDs carry the size. id(roboto_12) becomes Roboto at 12 px; id(roboto_bold_16) is Roboto Bold 16 px. Names containing material_symbols are treated as the icon font.
    • Live values. Put a format such as %.1f in the text and the sensor in Args, e.g. id(temp).state.
    • Layering. The first element in the list is drawn on top. Reorder the list to change what covers what.
    • Colors. Use Color IDs for custom colors. Pick a color with the picker, then use the converter in Settings to turn it into a Color ID.

    Known limitations

    • The preview is an approximation. Real font rendering on the device can differ by a few pixels.
    • Corner radius and line thickness are preview-only; ESPHome ignores them.
    • Triangles are not supported yet.
    • Icon search covers ~4,300 Material Symbols (Outlined) from fonts.google.com/icons.
    • YAML import reads lines, triangles, polygons, rings, gauges, images, graphs, QR codes, strftime clocks, clip regions and display pages:. Conditions, loops and variables are skipped and listed as warnings.
    • Screens wider than 480 px overflow the layout; use scale-to-fit.
    • The interface is not optimised for phones.
